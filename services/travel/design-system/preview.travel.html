本ページの位置づけ

  • 規則の正本は本ページではない。 規則は design.md と components.md、値は semantic.travel.json / primitive.travel.json にある。本ページはそれらを見える形にしたもので、規則の文章を持たない。各節の末尾に正本の所在を示す。
  • 値と一覧は生成している。 CSS 変数・色見本・スケールの 3 ブロックは tools/gen-preview-tokens.py が JSON から生成する。手で書き写した値はない。JSON を改訂したら python3 tools/gen-preview-tokens.py を実行する (一致確認は --check)。
  • 書体とアイコンは本番と同じものを読む。 LINE Seed JP / Noto Serif JP (Google Fonts・design.md §3) と Font Awesome 6 (同 §6)。
  • 🚧 は $status が placeholder のトークン。未取得 は正本に値が無く見本を描けないもの。いずれも Known Gaps に一覧がある。

C カテゴリ・特集

タイムセールsm (12px)。白面のためサイズ・ウェイトの条件なく成立する (≈16.10:1)。台が白系 (surface.subtle) のため 1px の枠線を引いている
冬の特集
写真の上。枠線は引かず面のみで分離し影・スクリムは用いない
面
color.label.category.surface (白 — accent で塗らない)
文字
color.label.category.text
アイコン
color.label.category.icon (campaign accent — 非テキスト要素に限る。字形とサイズは正本に定義がなく本ページの見本は例示)
枠線
color.label.category.border (= color.border.default #cccccc · 1px — 白系の面の上に置く場合のみ)

accent の帰属: accent を面として持つのは B 会員種別のみ、C は accent をアイコン (点) として持つ (owner-decisions.md §27)。分離手段: 上の見本の台は color.surface.subtle (#f9f9f9) で、白面との差は 1.05:1 (本 Repository で実測) と面のみでは境界が生じない (color.surface.default #ffffff の上では 1.00:1)。このため白系の面の上に置く場合にのみ color.label.category.border (#cccccc) の枠線を 1px 引く (owner-decisions.md §27-3 ⓕ)。枠線は白面上 ≈1.61:1 で非テキスト UI 要素の 3:1 に達しない (分離の補助であり、識別は文字 ≈16.10:1 が担う。適合宣言は行わない)。
