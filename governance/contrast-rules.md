# コントラスト規定 (横断規約)

- Status: Draft (内容レビュー待ち)
- Scope: コントラストの品質下限の**正本**。3 サービス (`travel` / `rental-car` / `inbound`) に共通して適用する Repository 横断の**運用規約**である。各 Design System の Foundation / Semantic / Component / `design.md` の**値**は共有しない (P1/ADR-0022) が、本規約は命名・運用規約の系に属するため横断で持つ (P2)。
- Position in Repository: `governance/contrast-rules.md` — Governance レイヤー (全サービス横断共通)。上流入口は リポジトリ全体入口 [../README.md](../README.md) と Governance レイヤー入口 [README.md](README.md)。現在判断の記録は [owner-decisions.md](owner-decisions.md) §44、レビュー・承認の手続は [review-approval-rules.md](review-approval-rules.md)。

本文書は、テキストと面のコントラストについて**下限の決め方**を定める。**個々の色値・トークン・組み合わせの実測値は定めない** — それらは各サービスの `design.md` が持つ (3 独立 DS の原則 P1/ADR-0022)。本規約は適用規格・達成レベルの正式確定・適合判定・適合宣言を行わない (§7)。Fact / 決定 / Open Issue を区別する。

---

## 1. 本規約を置く理由

- [事実] 従前、コントラストの品質下限は各サービスの `design.md` に**二値**で書かれていた — 「WCAG 2.2 AA を最低ラインとし DS には違反値を入れない (要求仕様 R9)」 ([../services/travel/design-system/design.md](../services/travel/design-system/design.md) §2) / 「WCAG 2.2 AA ・タップ領域・代替テキスト・色だけで伝えないを下限とする。例外は本書と `labels-tags.rental-car.md` に明示したものに限る」 ([../services/rental-car/design-system/design.md](../services/rental-car/design-system/design.md) §2.3)。
- [事実] 一方で DS は、AA (通常テキスト 4.5:1) に達しない組み合わせを**例外として複数運用している** — A 割引率ラベルの白文字 (scheme 逆色面上 2.78:1 / 2.15:1)・未入力状態の案内文字 (`#9E9E9E` 白面上 2.68:1)・campaign accent を文字色として明色面に置く場合 (3.68:1 / 3.50:1 / 3.38:1)。**規定の形 (二値) と運用の実態 (例外あり) が一致していない**。
- [事実] 例外の書き方は**用途名の列挙**であるため、列挙に載っていない表示要素が現れるたびに可否を判定できず、その都度 Owner 判断を取得する必要が生じていた。契機となった事例 = 国内レンタカー検索結果の「お得額」(他社比較の値引額) の文字色 (2026-09-19・[owner-decisions.md](owner-decisions.md) §44)。
- [決定] 下限を**テキストの役割**で段階化し (§4)、緩和を認める条件を**一般条件**として定める (§5)。これにより、定義に載っていない新しい表示要素についても、用途名を追加することなく各 DS の内部で判定できる状態にする。

## 2. 適用規格

- [決定] 目標とする達成レベルは **WCAG 2.2 AA** とする (要求仕様 R9)。関係する達成基準は 1.4.3 (テキストのコントラスト (最低限))・1.4.11 (非テキストのコントラスト)。
- [決定] コントラスト比は **WCAG 2.x の標準式**で算出し、算出した場所 (本 Repository か依頼元か) を記録する。
- [決定] §4 の役割 1・2・4・5 に与えた**コントラスト比の下限**は、WCAG 2.2 AA が定める値 (通常テキスト 4.5:1 / 大きなテキスト 3:1 / 非テキスト 3:1 / 装飾は対象外) をそのまま DS の運用単位へ割り当てたものである。ただし**役割 2 が対象とする文字の範囲は WCAG の「大きなテキスト」より狭い** — bold 側の下限を約 `18.7px` から `20px` へ引き上げているため (§3)。比は同じで、適用範囲は厳しい側にある。
- [事実] **役割 3 (冗長表現) のみは AA 未達を含む。** WCAG 2.2 の 1.4.3 が定める適用除外 (装飾・非表示・画像の一部) に冗長な強調テキストは**該当しない**ため、役割 3 は規格上の適用除外ではなく、**AA 未達を明示したうえでの限定的な許容**である。本規約はこれを「AA を満たしている」と言い換えない。
- [決定] 役割 3 を設ける理由は、AA 未達の運用が既に複数存在する実態 (§1) に対し、**許容の範囲と条件を事前に定めて予測可能にする**ことにある。範囲を定めずに用途ごとの個別判断を積み増す従前の運用より、逸脱の総量を抑えられると判断した。役割 3 は §5 の 4 条件と明示義務を伴い、条件を満たさないものは役割 1 として 4.5:1 を要求する。

## 3. 用語の定義

本節の用語は 3 サービス共通とする。各 DS の `design.md` が同じ用語を用いる場合、**正本は本節**である。

- **ウェイトの境界**: 「**bold**」は `700` 以上を指す (`800` を含む)。「**通常ウェイト**」は `700` 未満を指す。この 2 語で全ウェイトを排他的に二分する。
- **条件 (a)**: `24px` 以上 (**ウェイトを問わない**)。
- **条件 (b)**: `20px` 以上かつ **bold** (`700` 以上)。WCAG 2.2 上の bold 側の下限は約 `18.7px` だが、実運用上の誤差・フォント差を避けるため本規約では `20px` を下限とする。
- **(a) (b) のいずれも満たさない文字**: **(i) `20px` 未満のすべて**、および **(ii) `20px` 以上 `24px` 未満かつ通常ウェイト**。(a) (b) (i) (ii) で全サイズ・全ウェイトを網羅する。
- **「大きなテキスト相当」**: (a) (b) のいずれかを満たす文字 — **サイズ・ウェイトの条件**。**WCAG 2.2 の大きなテキストより範囲が狭い** (bold 側の下限を約 `18.7px` から `20px` へ引き上げているため)。WCAG の語をそのまま適用しない。
- **「大きなテキスト基準」**: WCAG 2.2 が大きなテキストに求める**コントラスト比 `3:1`** — **コントラスト比の基準であり、サイズ・ウェイトの条件ではない**。
- [決定] 上記 2 語は別概念であり混用しない。**コントラスト比が「大きなテキスト基準」を満たすことは、その文字を使用してよいことを意味しない** (使用可否は役割 = §4 と条件 = §5 で決まる)。
- **冗長表現**: 同じ情報が**同一画面の他の要素からも読み取れる**状態で置かれる、強調・要約・言い換えの表示。その要素が読めなくても、利用者が必要な情報を取り違えたり、操作に必要な判断ができなくなったりしないもの。

## 4. テキストの役割と下限

- [決定] コントラストの下限は、色そのものでも用途名でもなく、**その文字が画面で果たす役割**で決まる。DS は色の組み合わせを役割に割り当て、下限を満たすか判定する。

| 役割 | 内容 | 下限 | AA 未達の許容 |
| --- | --- | ---: | --- |
| **1. 必須情報** | 本文、操作に必要な情報、入力値、ラベル、エラーメッセージ、価格・条件・日時などの一次情報 | **4.5:1** | **§6 の個別例外条項として明記したものに限り認める。それ以外は認めない** |
| **2. 大きなテキスト相当** | 役割 1 の情報のうち、条件 (a) (b) のいずれかを満たす文字 (見出し・大きな訴求文字) | **3:1** | 該当しない (AA が定める下限そのもの) |
| **3. 冗長表現** | §3 の定義を満たし、かつ §5 の一般条件をすべて満たす強調・要約・言い換え | **3:1** | **認める (AA 未達を明示する)** |
| **4. 非テキスト UI 要素** | アイコン、境界線、状態の視覚的表示、グラフの要素 | **3:1** | 該当しない (AA が定める下限そのもの) |
| **5. 装飾・非情報** | ロゴ、ワードマーク、装飾、支給画像内の文字など、情報を伝えない要素 | 下限なし | 該当しない (規格の対象外) |

- [決定] 役割の判定は**厳しい側に倒す**。役割 1 と役割 3 のどちらとも読める要素は**役割 1 として扱う**。
- [決定] **1 つの要素が役割 1 と役割 3 を兼ねることはない。** 役割 3 は「同じ情報が他にもある」ことを前提とするため、その情報を担う唯一の要素は必ず役割 1 である。なお**役割 2 は役割 1 の部分集合**であり (表のとおり役割 1 の情報のうち条件 (a) (b) を満たす文字)、両者の併存は上記の排他の対象ではない。
- [決定] **`20px` 未満の文字は、ウェイトを上げても役割 2 の下限へ移れない** — 条件 (b) は `20px` 以上を要求するため、`20px` 未満は bold でも役割 2 に該当しない (条件 (i))。条件 (ii) (`20px` 以上 `24px` 未満かつ通常ウェイト) の文字は、bold (`700` 以上) にすれば条件 (b) を満たし役割 2 になる。
- [決定] **縁取り・影・半透明の重ねによってコントラスト不足を解決したものとして扱わない**。面が画像・グラデーションの場合の評価方法 (scrim の要否・評価点の取り方) は本規約では未定義である (§10)。

## 5. 役割 3 (冗長表現) を用いる一般条件

- [決定] 役割 3 を適用してよいのは、次の**すべて**を満たす場合に限る。ひとつでも欠ければ役割 1 として扱う。

1. **冗長性** — 同じ情報が同一画面の他の要素からも読み取れること。その要素が読めなくても、必要な情報の取得と操作の判断が成立すること。
2. **色に依存しない** — 色だけで意味を伝えていないこと。文言を併記していること (R9 / WCAG 2.2 AA)。
3. **3:1 は満たす** — 「大きなテキスト基準」に相当する 3:1 を下回らないこと。**3:1 を下回る組み合わせは役割 3 では扱えない** (個別の例外として §6 による)。
4. **明示** — AA (通常テキスト 4.5:1) 未達であることを、その組み合わせを記載する DS の該当箇所に明示すること。適合宣言を行わないこと (§7)。

- [事実] 本条件は**用途名を列挙しない**。ある表示要素が役割 3 に該当するかは、用途名が定義に載っているかではなく、上記 1〜4 を満たすかで判定する。
- [事実] 判定例 (国内レンタカー検索結果の「他社より N 円お得」) — 価格本体が同一画面に別途表示されており (条件 1)、文言「お得」を併記し (条件 2)、白面上 3.68:1 で 3:1 を満たす (条件 3)。役割 3 に該当し、AA 未達の明示 (条件 4) を伴って許容される。この判定に用途トークンの新設も例外条項の追加も要しない。

## 6. 3:1 を下回る組み合わせ

- [決定] 3:1 を下回る組み合わせは §4 のどの役割の下限も満たさない (役割 1 の文字であっても同じ)。用いる場合は、**当該 DS の `design.md` に個別の例外条項として明記**し、次をすべて記載する — 用途の限定・面の限定・実測値・AA 未達である旨・拡大を禁じる旨。**本節の例外条項として明記したものに限り、役割 1 の下限未達を許容する** (§4)。
- [決定] 個別の例外条項の新設は、**Owner (Web部責任者) の明示的な判断**を要する ([review-approval-rules.md](review-approval-rules.md) §8・§9・§20)。役割 3 の適用 (§5) はこれを要しない。
- [事実] 本規約の制定時点で、**3:1 を下回るため本節の扱いとなる**既存の例外条項は **3 件**ある (§9 が位置づけを与える既存の扱い 4 件のうち、役割 3 に収まる campaign accent の文字色を除いた残り) — A 割引率ラベルに限る白文字の例外 (2.78:1 / 2.15:1)・未入力状態の案内文字 (2.68:1)・C カテゴリ・特集ラベルの枠線 (1.61:1 / 1.53:1・非テキスト UI 要素の 3:1 未達)。いずれも本規約の制定によって適用範囲・実測値・トークンを変更していない (§9)。

## 7. 適合宣言の扱い

- [決定] 本規約および各 DS は、**適用規格・達成レベルの正式確定・適合判定・適合宣言を行わない**。「AA を満たす」という記述は、当該組み合わせの実測値が当該役割の下限を満たすという事実の記述であって、製品としての適合宣言ではない。
- [決定] 「**規則違反**」と呼ぶのは、**役割 1 の下限 (4.5:1) を満たさず、かつ §6 の個別例外条項に該当しない場合**、および役割 3 を §5 の条件を満たさずに用いた場合に限る。役割 3 として明示のうえ運用されている AA 未達、および §6 の個別例外条項として明記のうえ運用されている AA 未達は、規則違反ではない。
- [決定] AA 未達を「ブランド表現である」ことだけを理由に自動的に許容しない。

## 8. 判定主体と記録

- [決定] **役割の割り当てと下限の充足判定は、各サービスの DS が行う**。Owner の都度判断を要しない。
- [決定] 各 DS は、役割 3 として扱う組み合わせを `design.md` の検証表 (またはそれに相当する箇所) に**実測値とともに記載**し、AA 未達である旨を明示する。
- [決定] 次は Owner (Web部責任者) の判断を要する — ① §6 の個別例外条項の新設・変更、② ブランド色そのものの値の変更、③ 本規約の改定。
- [決定] 本規約と各 DS の記述が食い違った場合、**本規約が優先する**。各 DS は差異を欠陥として是正する。

## 9. 既存の例外条項の位置づけ

制定時点で 3 サービスの DS に存在する AA 未達の運用を、§4 の役割へ次のとおり対応づける。**個々の実測値・トークン・適用範囲の正本は各 DS の `design.md` のままであり、本節はその位置づけのみを示す。**

| 既存の扱い | 所在 | 実測 | 本規約での位置づけ |
| --- | --- | ---: | --- |
| campaign accent を文字色として明色面に置く | rental-car §2.4 代替規則 4 / travel §2.1 代替規則 3 | 3.68:1 / 3.50:1 / 3.38:1 | **役割 3** (§5 の条件を満たす場合)。従前は条件 (a) (b) を満たす文字に限っていたが、役割 3 に該当する場合はサイズ・ウェイトの条件を課さない |
| A 割引率ラベルに限る白文字の例外 (scheme 逆色面) | rental-car §2.4 / travel §2.1 | 2.78:1 / 2.15:1 | **§6 の個別例外** (3:1 未満)。既存の条項をそのまま維持する |
| 未入力状態の案内文字 `#9E9E9E` | rental-car §2.6 / travel §2.3 | 2.68:1 | **§6 の個別例外** (3:1 未満)。既存の条項をそのまま維持する |
| C カテゴリ・特集ラベルの枠線 `#CCCCCC` | rental-car §2.4 / travel §2.1 | 1.61:1 / 1.53:1 | **役割 4 の下限 3:1 に未達**。ラベルの識別は文字 (16.10:1) が担い、枠線は分離の補助である旨を各 DS が明示済み。§6 の個別例外として維持する |

- [事実] 本規約は上記 4 件の**適用範囲・実測値・トークンを変更しない**。位置づけを与えるのみである。
- [事実] campaign accent を**面 (背景)** として使用する場合の規則 (文字色は `color.text.onAccent` のみ・条件 (a) (b) を満たす文字に限る・(i) (ii) の代替規則) は各 DS の `design.md` が持つ規則であり、本規約は変更しない。面の上の白文字は「その面の上でその情報を担う唯一の文字」であるため通常は役割 1 であり、役割 3 には該当しない。

## 10. 本規約が定めない事項

- 個々の色値・トークン・組み合わせの実測値 (各サービスの `design.md`)。
- 面が**画像・グラデーション**の場合のコントラストの評価方法 (scrim の要否・評価点の取り方)。❓ 未定義。
- タップ領域・代替テキスト・色だけで伝えないなど、コントラスト以外の A11y 品質下限。`travel` は [../services/travel/design-system/design.md](../services/travel/design-system/design.md) §2、`rental-car` は [../services/rental-car/design-system/design.md](../services/rental-car/design-system/design.md) §2.3 が持つ。**`inbound` には品質下限の節が存在しない** (同 DS は Draft・未確定事項)。
- 適用規格・達成レベルの**正式確定**、適合判定、適合宣言 (§7)。
- ブランド色の値、および AA を満たす濃色段の実色 (実査待ちの `🚧` 仮色を含む)。
