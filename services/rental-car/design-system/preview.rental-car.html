  • 規則の正本は本ページではない。 規則は design.md・components.md・labels-tags.rental-car.md、値は semantic.rental-car.json / primitive.rental-car.json にある。本ページはそれらを見える形にしたもので、規則の文章を持たない。各節の末尾に正本の所在を示す。
  • 値と一覧は生成している。 CSS 変数・色見本・スケールの 3 ブロックは tools/gen-preview-tokens.py が JSON から生成する。手で書き写した値はない。JSON を改訂したら python3 tools/gen-preview-tokens.py --service rental-car を実行する (一致確認は --check)。
  • 3 独立 DS の原則を維持する。 本ページが読むのは services/rental-car/design-system の JSON だけで、国内宿泊 (travel) のファイルを参照・共有しない (design.md 独立性・P1/ADR-0022)。

  • 🚧 は $status が placeholder のトークン。未取得 は正本に値が無く見本を描けないもの。いずれも Known Gaps に一覧がある。

文書レベルの見出し (h1〜h6)

既定は breakpoint.lg (1024px) 以上に適用される値で、1024px 未満では h1〜h4 の段を 1 つ下げる (h5・h6 は 1rem のまま下げない)。段を移す境界は 1024px の 1 つのみで、640 / 768 / 1280px では変えない。この表の範囲内での段下げは §3.1 の「既定から外れる」に該当しないため、画面ごとの都度の承認を要しない。文書レベルの見出しには実寸が 4 の倍数である段のみを用いる (sm 14px・lg 18px は見出しに用いない — lg は font.display.mdSize = 車種クラス名が引き続き参照する)。書体は役割で選ぶため要素と書体の対応は固定されず、役割が Display・Hero・車種クラス名にあたる場合は h1 であっても font.display.family (明朝) を明示的に選択してよい。サイズ・太さ・行間の既定は書体の選択と独立で、明朝を選んでも下表の値と 700・1.3 がそのまま適用される (design.md §3.1)。

見本欄はこのウィンドウの幅に追従する — 。幅を 1024px の前後で変えると段が切り替わる。
